# Чек-лист проверки на машине

Версия на момент составления: прошивка `FW-2026.11.04.91-CMD`, приложение `PWA leaf-v27`.
Порядок — от простого к сложному. Всё, что помечено ⚠️, требует внимания, но не обязательно является ошибкой.

---

## 1. Какой интерфейс открывается

- [ ] Зайти по адресу платы (`http://<ip>/`) — должна открыться **лёгкая страница**: крупно заряд и запас хода.
- [ ] Нажать «Красивый вид» — открывается полное приложение.
- [ ] Вернуться: «Ещё → Упрощённая страница».
- [ ] Перезагрузить плату (или подождать перезапуска) — должна остаться та версия, которую выбрали последней.

⚠️ Если после перезагрузки вернулось не то — сообщите, это про сохранение настройки в NVS.

---

## 2. Лёгкая страница

- [ ] Цифры обновляются сами (раз в 4 секунды), надпись «данные свежие»/«обновлено N с назад» идёт.
- [ ] «Обновить» — обычное нажатие, сразу опрашивает плату.
- [ ] **Удержание**: «Климат», «Зарядить», «Свет», «Свет + сигнал», «Закрыть» — срабатывают только если держать ~0,6 с, кнопка подсвечивается и вибрирует.
- [ ] Короткое касание (тап) ничего не отправляет.
- [ ] Во время выполнения внизу появляется «выполняется — около 8 секунд», кнопки блокируются.
- [ ] Если нажать вторую команду во время первой — появится «плата занята предыдущей командой» (это правильное поведение).

---

## 3. Свет и сигнал (новое)

- [ ] «Свет» (удержание) — примерно **15 вспышек**, около 8–10 секунд.
- [ ] «Свет + сигнал» — вспышки и гудки в том же ритме.
- [ ] «Поиск моей машины» на вкладке «Гараж» (удержание) — то же самое: свет + сигнал.

⚠️ Если вспышек меньше или они идут рывками — скажите, поправлю длительность/паузу (сейчас 120 мс вспышка, 380 мс пауза).
⚠️ Если машина не реагирует вовсе — проверьте, что команда принята: в приложении не должно быть «команда недоступна».

---

## 4. Климат и таймер

- [ ] Дистанция → кнопки длительности 5/10/15/20/30, выбранная подсвечена.
- [ ] Удержать «Климат» — включается, появляется полоса «климат выключится через N мин».
- [ ] Полоса убывает раз в секунду, по окончании исчезает, климат выключается.
- [ ] Повторное удержание — климат выключается сразу.
- [ ] На лёгкой странице климат включается тоже (таймер 15 минут, 22 °C).

---

## 5. Телеметрия

- [ ] Напряжение, ток, мощность меняются на ходу/при климате (не стоят).
- [ ] Температура батареи и салона приходят, когда машина активна (движение, зарядка, климат).
- [ ] Если данных нет — показывается «—», а не старое значение.
- [ ] `fage` в `/api/status` растёт, когда машина спит; значения при этом уходят в «—».

---

## 6. История

- [ ] Один раз: «Поездки → Очистить историю» и «Зарядки → Очистить историю» — чтобы убрать старые записи с нулевыми километрами.
- [ ] Проехать 1–2 км — появляется поездка с **реальными км** (из одометра), временем, кВт·ч, зарядом до/после.
- [ ] Тумблер «Записывать трек поездок»: выключить, проехать — новая поездка **без** карты; включить, проехать — с картой (если есть GPS).
- [ ] Начать зарядку — появляется сеанс, кВт·ч **положительные**, по окончании дописывается результат.
- [ ] Вкладка «Зарядки» открывается из нижнего меню (между «Состояние» и «Поездки»).

---

## 7. Разработчик

- [ ] «Ещё → Для разработчика», пароль `1985`.
- [ ] CAN-монитор: строки по ID, подсветка изменений, счётчик «Изм.» растёт у активных кадров.
- [ ] Фильтр по ID: ввести `1D6` — остаются только совпадающие.
- [ ] «Отметить нажатие» → нажать кнопку в машине 5–10 раз → в колонке «Наж.» у нужного ID растёт число.
- [ ] «＋» у строки → сохранить под именем → запись появилась в «Мои команды».
- [ ] «Разрешить отправку» (10 минут) → «▶» → подтверждение → «Отправлено: N из N».
- [ ] Без разрешения «▶» → «Сначала разрешите отправку».
- [ ] Прокрутка таблицы вверх пальцем не перезагружает страницу.

---

## 8. Связь

- [ ] Wi-Fi: страница открывается и в домашней сети, и через собственную точку доступа платы.
- [ ] В режиме точки доступа страница не обрывается посреди загрузки (перезапуск радио отключён, пока есть клиент).
- [ ] MQTT: приложение на телефоне показывает данные, команды доходят.
- [ ] «Только звонок»: звонок с разрешённого номера — голосовое подтверждение, климат переключается; Wi-Fi при этом работает.

---

## 9. Что прислать, если что-то не так

1. Что делали (какая кнопка, где).
2. Что ожидали и что получилось.
3. Если есть доступ к странице платы — скриншот или содержимое `http://<ip>/api/status`.
4. Время (по часам) — по нему я найду событие в логах/истории.

Быстрая автоматическая проверка с ноутбука:

```powershell
powershell -File tools\qa-status.ps1 -Board leaf.local
```
