## 2026-10-21 — сессия: веб-UI платы, captive portal, планы пушей

- PWA-разметка вшита в прошивку (`webapp_html.h` через
  `tools/mkwebapp.ps1`) — веб-UI платы доступен без интернета.
- Включена точка доступа платы `Leaf_Control` (полный POST
  `/settings_save`, проверено чтением настроек после ребута).
- Реализован captive portal (wildcard DNS + редирект `onNotFound`);
  OTA-попытка не применилась (плата осталась на старой прошивке) —
  отложено до отдельной заливки.
- Исследование push-уведомлений: у PWA нет push-инфры; серверный мост
  MQTT→Web Push не нужен — **принято решение о нативном Android
  приложении**: фоновый MQTT + локальные уведомления без сервера/FCM,
  WorkManager с настраиваемым интервалом (по умолчанию ~15 мин) +
  опционально foreground-сервис.
- Подготовлен план зеркалирования проекта в этот репозиторий.

## 2026-10-22 — сессия: баг чекбокса модема, OTA, зеркало репо

- **Расследование бага «SIM800 не сохраняется»**:
  - плата оказалась недоступна по старому IP (DHCP сменил адрес,
    позже — `192.168.137.215`); mDNS `leaf.local` работал;
  - проверено: `locking_enabled` и прочие чекбоксы сохраняются в NVS —
    путь сохранения корректен;
  - **корень найден в `ui.h`**: тег `<input>` для `modem_sim800` и
    `modem_a7670` закрывался `>` **до** вставки условного `checked` —
    атрибут рендерился текстом, галка не отображалась никогда;
    сохранение при этом работало (подтверждено serial-логом
    `[modem] enabled (SIM800)` после ребута).
- **Фикс**: `>` перенесён после условного `checked` (как у остальных
  чекбоксов); captive portal из исходников откачен (решение —
  заливать только фикс).
- **OTA**: сборка 1 277 057 байт (97% flash); первая заливка
  оборвалась на ~640 КБ (`curl 52`), повтор под serial-записью (COM,
  115200) — `### OTA success: 1277360 bytes ###`, ребут.
- **Проверки**: `GET /settings` — `onchange="mCheck('800')" checked>SIM800`;
  `/generate_204 → 404` (captive portal не заливались — по решению);
  APN `internet.beelina.ru` на месте; `[modem] enabled (SIM800)` в логе.
- **Зеркало репозитория**: `.gitignore` (build/, *.bin, *.apk),
  `firmware/LeafControl/` (24 файла, без build-артефактов),
  `tools/mkwebapp.ps1` (адаптирован под структуру репо: PWA в корне,
  выход в `firmware/LeafControl/`), `docs/` (PLAN, CHANGELOG,
  RELEASES, AGENT, WORKLOG); сборка из скопированных исходников
  проверена (совпадает размер).
