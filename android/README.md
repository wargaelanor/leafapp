# Leaf Control для Android

Нативное приложение на Kotlin + Jetpack Compose. Дизайн повторяет PWA, но
интерфейс полностью нативный: без WebView, HTML и загрузки страницы.

## Что умеет

- **Гараж** — фото Leaf, заряд, запас хода, быстрое включение зарядки,
  вспышка фар, двери, климат.
- **Дистанция** — климат с температурой и длительностью, зарядка, замки,
  свет, сигнал, обновление данных.
- **Состояние** — заряд, запас, мощность, напряжение, ток, температуры,
  SOH, пробег, замки, свет, климат, Wi-Fi, прошивка.
- **Зарядки** и **Поездки** — история, стоимость по тарифу, экспорт CSV,
  очистка.
- **Ещё** — настройки, проверка обновлений, сведения о приложении,
  настройки платы и OTA.
- **Свайпы** между вкладками и вертикальная прокрутка. Данные обновляются
  на месте, без перезагрузки экрана.
- **Офлайн** — последние данные машины и история сохраняются на телефоне;
  приложение открывается и показывает их без интернета.
- **Фоновая служба** — локальный HTTP или MQTT (WSS), уведомления о
  зарядке, низком заряде, офлайне и завершении поездки.
- **Автообновление** — из GitHub-релиза `android-v1.10` и новее.
- **Ярлыки** — долгое нажатие на иконку: «Открыть», «Закрыть»,
  «Климат вкл», «Климат выкл».
- **Иконка** — как у PWA.

## Установка

1. Возьмите `dist/LeafControl-1.10-debug.apk`.
2. Разрешите установку из неизвестных источников.
3. При первом запуске разрешите уведомления.
4. Откройте «Ещё → Настройки», проверьте связь и включите фоновый режим.

Первый переход с 1.1–1.9 на 1.10 можно сделать вручную или через
«Проверить обновление» в старой версии.

## Связь

- **Авто** — сначала локальная плата, затем MQTT.
- **Локально** — телефон в той же Wi-Fi, что и плата. Плата ищется сама
  по mDNS; кнопка «Найти плату» в настройках сканирует локальную сеть.
- **MQTT** — сервер, порт, пользователь, пароль и Vehicle ID задаются
  в настройках приложения.

## Сборка

```powershell
$env:ANDROID_HOME="C:\Android\Sdk"
& "C:\Gradle\gradle-8.9\bin\gradle.bat" -p android assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

Публикация обновления:

```powershell
powershell -File tools\release-android.ps1
```

## Ограничения

- MQTT-брокер должен отдавать WebSocket; приложение пробует путь `/` и `/mqtt`.
- Debug-сборка не подписана для Google Play; для личного использования этого
  достаточно.
