# Leaf Control для Android

Нативное приложение на Kotlin + Jetpack Compose для платы Leaf Control.

## Что умеет

- **Локальный режим** — HTTP к плате (`/api/status`, `/api/trips`, `/api/charges`, команды). Работает через Wi-Fi платы или домашнюю сеть.
- **MQTT (WSS)** — те же топики, что у PWA: `ovms/<user>/<vehicle>/metric/#`, команды в `client/pwa/command/c`.
- **Фоновая служба** — постоянное уведомление, автоподключение, восстановление после перезапуска.
- **Уведомления**: зарядка началась/завершена, низкий заряд, поездка завершена, плата не в сети.
- **История**: в локальном режиме синхронизируется с платой; в MQTT-режиме телефон записывает поездки и зарядки сам.
- **Тариф** день/ночь и стоимость в рублях.
- Тёмная тема, русский интерфейс.

## Установка

1. Возьмите `dist/LeafControl-1.0-debug.apk` (или `app/build/outputs/apk/debug/app-debug.apk`).
2. Перекиньте на телефон, разрешите установку из неизвестных источников.
3. При первом запуске разрешите уведомления.
4. В «Ещё → Разрешить работу в фоне» отключите оптимизацию батареи для приложения.

## Настройка

- **Авто** — сначала пробует локальный HTTP, если плата недоступна, уходит в MQTT.
- **Только локально** — телефон должен быть в той же Wi-Fi, что и плата. Адрес по умолчанию `192.168.4.1` (точка доступа платы); для домашней сети введите IP платы.
- **MQTT** — сервер `m5.wqtt.ru`, порт `15871`, пользователь/пароль и Vehicle ID как в PWA.

Приложение не использует FCM и сторонние серверы: уведомления приходят по MQTT или локальному HTTP, пока работает foreground-служба.

## Сборка

```powershell
$env:ANDROID_HOME="C:\Android\Sdk"
& "C:\Gradle\gradle-8.9\bin\gradle.bat" -p android assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Ограничения

- `leaf.local` на Android не всегда резолвится через mDNS — надёжнее вводить IP платы.
- MQTT-брокер должен отдавать WebSocket; приложение пробует путь `/` и `/mqtt`.
- В MQTT-режиме история пишется по телеметрии (одометр, мощность), поэтому короткие перемещения менее точны, чем история на самой плате.
- Debug-сборка не подписана для Google Play; для личного использования этого достаточно.
